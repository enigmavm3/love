兩個人，怎麼開始雙向翻譯？

準備你和對方的 LINE 帳號，使用一般 LINE 群組。只把小幫手加為好友，還不等於已啟用你們的群組翻譯。

  1. 01 / Add a friend

    把翻譯小幫手加為好友

    在手機點選下方「加入 LINE，開始使用」，依 LINE 畫面加入翻譯小幫手好友。

    加入 LINE，開始使用
  2. 02 / Make a group

    建立你、對方與小幫手的群組

    建立一般 LINE 群組並邀請對方，再從群組選單的「邀請」選擇翻譯小幫手。已有兩人群組也可以直接邀請小幫手加入。

    完成後，檢查成員清單中是否同時有你、對方和翻譯小幫手。

  3. 03 / Start talking

    雙方各傳一句完整的母語訊息

    例如你先傳「今天過得怎麼樣？」，再請對方用自己的語言回覆。小幫手會自動辨識語言；若出現語言引導，依畫面完成即可。

    先用完整短句測試，確認雙方都看得到需要的譯文，再繼續日常聊天。

使用的是一般 LINE 群組，不是 LINE 社群（OpenChat），也不是直接讀取你和對方原本的一對一聊天室。

雙向聊天，會是什麼樣子？

你傳送中文

對方用英文回覆

以上為對話與譯文示意，不是實際使用者訊息；譯文會依上下文而不同。

重要的約定可以寫清楚日期、時間與地點；遇到語氣或稱謂不確定時，請對方再確認一次。

常見問題 FAQ

支援哪些語言？日文、韓文可以用嗎？

核心支援繁體中文、印尼語、越南語、泰語、英文與菲律賓語（Tagalog）。日文、韓文等延伸語言以 Beta 形式提供，品質保障與核心六語不同；建議先用你們的日常對話試用，確認適合再付費。

一定要三個人嗎？只有我和伴侶也能用？

兩位使用者加上翻譯小幫手，就能建立翻譯群組，不需要再找第三位真人。小幫手需加入群組，才能處理該群組的訊息。

可以直接翻譯原本的一對一聊天嗎？

群組雙向翻譯需要把雙方與小幫手放在同一個一般 LINE 群組。小幫手不會直接讀取你與對方原本的一對一聊天室；請在新建或既有的群組中聊天。

免費翻譯有多少？每個月會重置嗎？

每個群組終身共 50 則免費翻譯，包含語音訊息翻譯，不會每日或每月重置。用完後可依需求選擇加值包或付費方案，詳見方案與價格。

如何付費？會自動續費嗎？

付費與群組管理透過翻譯小幫手的一對一聊天室進行。付費方案採單次購買 30 天，不自動扣款；請依使用指引選擇要使用的群組，確認方案與金額後再付款。完整額度與價格請看價目表與使用說明。

可以翻譯語音訊息或 LINE 通話嗎？

語音訊息翻譯依方案與可用額度提供；LINE 語音／視訊通話中的即時口譯不在本服務範圍內。請先確認方案是否符合你們的使用方式。

對方需要另外安裝 App 嗎？

雙方使用 LINE 並加入同一個群組即可，不需要另外安裝翻譯 App。

聊天隱私要注意什麼？

加入小幫手前，先讓群組成員了解訊息會由翻譯服務處理。個人資料的處理方式與相關權利請閱讀隱私權政策；請避免傳送密碼、驗證碼等不適合分享的資訊。

小幫手沒回應，先檢查這四件事

  1. 確認是一般 LINE 群組，而且成員清單裡有翻譯小幫手。
  2. 請雙方各發一句完整的母語訊息，不要只用貼圖或單一表情測試。
  3. 查看是否有語言設定引導，並確認雙方使用的語言。
  4. 回到小幫手的一對一聊天室，依指引查看群組額度與付費狀態。
